Оболочка опубликована

Это клиентская часть приложения. Здесь не будет ни секретов, ни данных: браузер работает с GitHub API от вашего имени по токену, который вы вводите сами.

Что уже готово

  • Светлая и тёмная темы с учётом системной настройки
  • Индикатор текущего тарифа DeepSeek в подвале

Что дальше

  1. PIN-гейт: PIN расшифровывает токен GitHub, ничего не хранится в открытом виде
  2. Настройки: форма секретов и чек-лист
  3. Каналы: добавление и удаление
  4. Дашборд: запуск дайджеста и статус прогона
  5. Дайджест, шаблоны, статистика стоимости

Бэкенд и данные живут в приватном репозитории tg-digest-core.
