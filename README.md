# tg-digest

Веб-приложение для дайджестов из Telegram: по кнопке читает сообщения из выбранных
каналов, групп и форумов, сжимает их через DeepSeek и отдаёт короткую сводку по темам —
в браузер и в Telegram-бота.

**Что экономит:** вместо 2000 сообщений — одна страница по темам, без воды.

## Живой интерфейс

**<https://sergkursk-lgtm.github.io/tg-digest/>**

## Из чего состоит

| Часть | Где | Что делает |
|---|---|---|
| UI | этот репозиторий, `frontend/` | статическая страница на GitHub Pages, без сборщиков и зависимостей |
| Бэкенд | [`tg-digest-core`](https://github.com/sergkursk-lgtm/tg-digest-core) (приватный) | Python в GitHub Actions: Telethon → DeepSeek → рендер → отправка |
| Данные | ветка `data` приватного репозитория | дайджесты, каналы, стили, статистика стоимости |

Секретов в этом репозитории нет и не будет: страница статическая, а доступ к GitHub API
браузер получает по токену, который вы вводите сами и который хранится зашифрованным
вашим PIN-кодом.

## Интерфейс

Три вкладки внизу — **Дайджесты**, **Каналы**, **Настройки** — и больше ничего в корне.
Всё, что можно сделать, живёт на одной из них или открывается поверх неё.

```
┌─ Дайджесты ─────────────────────────────┐
│  расход за месяц, список собранных      │
│  [＋ Собрать] → каналы → стиль → период │
└─────────────────────────────────────────┘
        │ тап по дайджесту
        ▼
┌─ Дайджест ──────────────────────────────┐
│  краткий ◀─▶ полный                     │
│  тезисы по топикам                      │
│  [Спросить у ИИ: что там про…]          │
│  диалог вопросов + ссылки на сообщения  │
└─────────────────────────────────────────┘
┌─ Каналы ────────────────────────────────┐
│  все чаты аккаунта с переключателями    │
│  выбранные: стиль и период по каналу    │
└─────────────────────────────────────────┘
┌─ Настройки ─────────────────────────────┐
│  статус, Telegram, DeepSeek, доставка,  │
│  бюджет, лимиты, тема                   │
│  ▸ шаблоны и стили   ▸ статистика       │
└─────────────────────────────────────────┘
```

- **Вход — только PIN**, набранный на своей экранной клавиатуре: системная не выезжает и
  ничего не перекрывает. Четыре цифры, автоотправка, блокировка после пяти ошибок.
- **Спросить у ИИ.** Под каждым дайджестом есть строка вопроса. Ответ строится заново по
  исходным сообщениям канала за период дайджеста — сырые сообщения никуда не сохраняются,
  в ответе остаются только ссылки на них.
- **Стиль на один запуск.** В шторке «Новый дайджест» можно выбрать стиль (краткий /
  детальный / аналитический) и период, не меняя настройки канала.

## Как пользоваться

1. Откройте страницу, введите токен GitHub и PIN — токен будет зашифрован PIN-ом.
2. Приложение покажет короткий список того, что осталось настроить: приложение Telegram,
   ключ DeepSeek, доставка в бота, каналы. Каждый пункт открывается в один тап.
3. Дальше вход — только PIN.
4. Вкладка «Каналы»: отметьте чаты, из которых нужны дайджесты.
5. «Дайджесты» → «Собрать» — дайджест появится на странице и придёт в Telegram-бота.

Полная инструкция по получению `api_id`, `api_hash` и ключей —
в [README бэкенда](https://github.com/sergkursk-lgtm/tg-digest-core#настройка-по-шагам).

## Как Mini App в Telegram

Тот же адрес открывается кнопкой прямо в боте: рядом с полем ввода есть кнопка
**«Дайджесты»**. Внутри Telegram приложение берёт тему клиента и безопасные отступы, а не
настройки операционной системы, поэтому выглядит родным; кнопка «Назад» клиента работает
как «шаг назад» внутри приложения.

Что стоит знать при первом открытии из бота: webview Telegram — **другое хранилище**, чем
обычный браузер, поэтому токен GitHub (и PIN) придётся ввести там ещё раз. Дальше он
запоминается.

Регистрация приложения в BotFather не требуется для кнопки в чате — она настраивается через
Bot API (`setChatMenuButton`). Профильная кнопка «Открыть приложение» и ссылка вида
`t.me/<бот>/<приложение>` появляются только после настройки Mini App в BotFather.

## Разработка

Сборка не нужна: файлы отдаются как есть.

```bash
# тесты фронтенда
node --test tests/*.test.mjs

# локальный просмотр
python3 -m http.server 8000 --directory frontend

# проверка на живом репозитории (нужен токен): читает все файлы, которые читает UI,
# и опционально запускает digest.yml в режиме dry-run
GITHUB_TOKEN=... node tools/smoke-api.mjs [--dispatch]

# проверка, что запечатывание секретов принимается GitHub
GITHUB_TOKEN=... node tools/verify-seal.mjs
```

Правила проекта — в [`AGENTS.md`](AGENTS.md), план интерфейса и что из него сделано —
в [`docs/UI_PLAN.md`](docs/UI_PLAN.md), назначение вендорного кода —
в [`frontend/vendor/README.md`](frontend/vendor/README.md).

## Деньги

Модель — `deepseek-flash`. Peak — Пн–Пт 01:00–04:00 и 06:00–10:00 UTC, всё остальное
дешевле вдвое. Текущий тариф и расход за месяц видны первыми строками на вкладке
«Дайджесты», подробная разбивка по дням — в настройках. Бюджет по умолчанию $5/мес;
вопросы к ИИ тратят из того же лимита.
